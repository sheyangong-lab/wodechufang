# 共享厨房 App 实施计划 v1.0

> **For agentic workers:** 按“执行方式”（第六节）逐里程碑执行；每个里程碑开工前依据本计划对应章节生成任务级 TDD 计划，步骤用 `- [ ]` 勾选跟踪。
>
> **Goal:** 复刻共享厨房点菜小程序为 Android + 鸿蒙双端 App：浅黄暖色主题、记账（Excel 导出）、VIP 会员与后台管理。
>
> **Architecture:** uni-app x 单一代码库编译双端；Spring Boot 单体后端 + MySQL；Vue3 后台管理系统；Excel 由服务端生成。
>
> **Tech Stack:** uni-app x (Vue3+TS) · Spring Boot 3 (Java 17) · MySQL 8 · Redis · MinIO · EasyExcel · Vue3 + Element Plus（若依二开）
>
> **蓝本文档:** [页面功能分析.md](./页面功能分析.md)（UI 逐页蓝本）· [复刻方案与需求设计.md](./复刻方案与需求设计.md)（需求/色板/数据模型）

## Global Constraints（所有任务默认携带）

- 主题色值严格取自设计方案第二节：背景 `#FFFBF2`、主色 `#F5C15C`、主按钮 `#EFA63C`、标题字 `#3D3325`、次文字 `#8C7F6A`、收入橙 `#E8842E`、支出绿 `#5BA47C`、会员金渐变 `#E8C87E→#D9A441`。
- 金额一律整数「分」存储，展示层 ÷100 保留两位小数；禁止浮点存金额。
- 客户端接口前缀 `/api/**`，JWT Bearer 鉴权；后台接口 `/api/admin/**`，独立管理员角色；所有业务接口按 `kitchen_id` 校验请求者成员身份。
- 客户端最低支持：Android 8.0（API 26）、HarmonyOS NEXT（API 12）。
- UI 文案与布局对照《页面功能分析.md》对应截图编号；颜色按《复刻方案》第二节替换原紫色。
- 每个任务一次 commit，Conventional Commits（`feat:`/`fix:`/`test:`/`docs:`）。
- 15 张截图中 13/14 为同页滚动，视为 16 个页面；未覆盖页面（下单确认、菜谱详情、登录等）按设计方案第一节自行设计。

## 〇、技术选型决策（本次定稿）

| 项 | 决定 | 理由 |
|----|------|------|
| 客户端 | **uni-app x（Vue3 + TS）** | 与小程序组件模型最接近、复刻 UI 成本最低；一套代码编译 Android APK + 鸿蒙 HAP；DCloud 与华为合作支持鸿蒙 NEXT，中文生态和支付/推送/分享插件最全 |
| 备选 | Flutter（OpenHarmony SIG 版） | 若尖峰任务失败则切换；性能更好但鸿蒙插件生态需逐个验证 |
| 后端 | Spring Boot 3 单体 | 单人可维护；EasyExcel 生态成熟 |
| 后台 | 若依 RuoYi-Vue3 二开 | 省去登录/权限/菜单脚手架，聚焦 VIP 与厨房管理两个核心模块 |

**Go/No-Go 门（M1-T1 尖峰）**：2 个工作日内同一工程同时产出可运行 APK 与 HAP，并跑通网络请求、图片上传、文件分享三个关键能力。任一失败超 2 天 → 切换 Flutter 预案，重估 M1 工期（+3 天）。

## 一、仓库结构（monorepo）

```
shared-kitchen/
├── client/                     # uni-app x 客户端
│   ├── src/pages/kitchen/      # 厨房 Tab（点单/修改/菜谱表单/分类管理）
│   ├── src/pages/order/        # 订单 Tab（列表/筛选/下单确认/随机点菜）
│   ├── src/pages/ledger/       # 账本 Tab（总览/记一笔/明细/统计/导出）
│   ├── src/pages/fridge/       # 冰箱 Tab（列表/放入食材/类别管理）
│   ├── src/pages/profile/      # 我（个人中心/会员中心/厨房管理入口）
│   ├── src/components/         # 通用组件（EmptyState/ActionSheet/Calendar…）
│   ├── src/api/                # 接口封装（按模块分文件）
│   ├── src/stores/             # Pinia：auth/cart/kitchen
│   └── src/styles/theme.ts     # 色板常量（Global Constraints 色值）
├── server/                     # Spring Boot
│   └── src/main/java/com/sharedkitchen/
│       ├── common/             # Result<T>、JWT 过滤器、全局异常
│       └── module/{user,kitchen,dish,order,fridge,ledger,vip,admin}/
├── admin/                      # RuoYi-Vue3 后台
└── docs/                       # 本项目三份文档迁入
```
