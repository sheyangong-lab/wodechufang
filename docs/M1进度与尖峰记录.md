## 富文本制作过程（2026-08-29，计划内欠账补全 M2-T3）

- **实现**：edit.vue 用 uni-app `editor` 组件 + 自定义工具条（B/I/U/有序/无序列表/插图≤8张/清空），插图走已有上传接口后 `insertImage`；steps 字段存 HTML（TEXT 列天然兼容）；detail.vue 用 `rich-text` 渲染，旧纯文本保持编号行渲染（双格式兼容）。
- **跨端坑（重要，复用）**：
  1. editor 的 EditorContext 必须用 `uni.createSelectorQuery().select('#id').context(cb)` 获取——`@ready` 的 e.detail 在 H5 端为空；
  2. H5 端 `setContents({html})` 无效（静默失败），**必须传 `{delta: {ops:[{insert:'...\n'}]}}`**（quill 原生格式）；delta 失败再回退**逐行** `insertText`（多行文本一次 insertText 会丢行）；
  3. 程序化灌入会触发 input 事件 → 必须 suppressInput 标志屏蔽，否则 editorTouched 误置 true；
  4. 保存防护：未触碰编辑器时提交 originalSteps，防止灌入失败清空用户历史步骤（真机+服务端双重验证 PASS）。
- **验证**：IAB 浏览器 DOM snapshot——编辑器三行步骤完整灌入（1、打蛋/2、炒蛋/3、放番茄翻炒）；点保存后服务端 steps 原样保留（对账 PASS）。

**新踩坑（防复发）**：
1. **pkill 与启动语句同命令 = 自杀**（模式匹配到同 cmdline 的 java -jar 字样，共犯 3 次）——pkill 必须单独一条命令执行。
2. 打包失败时旧 jar 仍在，setsid 会继续拉起旧版本占住 8080（表象是"接口行为没变"）——重启前先确认 PKG=0。
3. `@NotBlank` 不能用于 Long（→`@NotNull`）；新 Controller 的 `Validated` import 一定放 `org.springframework.validation.annotation`（犯 4 次）。
4. 同名 Filter Bean：`@Component` 与 `@Bean` 注册二选一；`@Bean` 方法参数不能实例化未注册类，手动 `new`。
5. 多 Sheet Excel 必须用 `ExcelWriter.build()` + `writerSheet().build()` + `write()` + `finish()`，链式 sheet().doWrite() 会互相覆盖。
