## 环境适配决策（已确认的用户约束）

1. **数据库**：开发 SQLite（嵌入式免服务） / 生产 PostgreSQL（保留字规避：表名用 `users`）。
2. **服务端**：`java -jar` 直接运行，不使用 Docker。
3. Maven 安装在 `~/.local/opt/apache-maven-3.9.11`（无 sudo，仅用户目录）；构建命令需 `JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64`（系统默认工具链混乱：runtime 26 + javac 21）。

## 已修问题（防复发）

| 问题 | 根因 | 修复 |
|------|------|------|
| `不支持发行版本 21` | JAVA_HOME 为空，Maven 落在 26/21 混合工具链 | 构建命令固定 JAVA_HOME=JDK21；已记录 |
| SQLite 启动报 `path does not exist` | xerial jdbc 不建父目录 | main() 启动前 `Files.createDirectories(./data)` |
| H5 构建 `sass not found` | 模板未带 SCSS 预处理器 | `npm i -D sass` |
| Apache 官方源/清华/阿里镜像 404 或超时 | 镜像版本目录不一致 | Maven 从 repo.maven.apache.org 直下 |
