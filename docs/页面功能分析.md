# 共享厨房 App · 截图功能分析（复刻蓝本）

> 分析对象：17 张微信里分享的小程序截图（原产品为「共享厨房点菜系统」小程序，顶部有小程序胶囊按钮）。
> 目标：复刻为 **安卓 App + 适配鸿蒙（HarmonyOS）** 的应用。
> 截图顺序按文件名时间戳排列，即原作者的实际操作浏览顺序。

---

## 一、产品总体结构

底部导航共 **5 个 Tab**：

| Tab | 图标 | 核心功能 |
|-----|------|----------|
| 厨房 | 厨师帽 | 菜谱菜单展示、点单/修改模式、菜谱分类管理 |
| 订单 | 清单 | 厨房订单 + 我下过的单，按日期/状态筛选 |
| 冰箱 | 冰箱 | 食材库存管理（保质期、过期提醒、匹配菜谱） |
| 管理 | 罗盘 | 厨房设置、成员、额度、20+ 扩展功能入口 |
| 我 | 笑脸(带红点) | 个人中心、积分、会员、通知中心 |

**产品形态**：多人共享一个"厨房"（类似家庭/宿舍/小团队共用菜单）。厨房有唯一「厨房码」，成员凭码加入；店长（创始人）管理菜单，成员/顾客下单。

## 三、核心用户流程（截图顺序还原）

```
厨房(点单,空) ──点「添加菜谱」──► 弹窗选添加方式
   ├─ 手动添加 ──► 编辑菜谱表单 ──发布──► 菜单出现
   ├─ 快捷导入 ──► 导入页(粘贴链接) ──导入──► 菜单
   ├─ 克隆菜谱/广场偷菜/批量添加(会员) ──► 各自流程
厨房(修改模式) ──点菜谱图──► 编辑/下架/删除
厨房底部「随机选菜」──► 今天吃什么(随机点菜) ──► 加入购物车 ──下单──► 生成订单
订单页 ──按日期/状态筛选(日历弹窗+状态弹窗)──► 店长处理(完成/退单)
冰箱页 ──放入食材(表单)──► 食材列表 ──临期提醒/匹配菜谱
管理页 ──厨房成员──► 成员管理(邀请/搜索/权限/历史订单)
我 ──个人中心(积分/会员/通知/客服)
```

## 四、商业化设计（复刻时可参考）

1. **会员体系**：厨房会员（升级厨房）+ 个人会员（7项特权）；会员功能包括批量添加、高级设置、下单表单、厨房桌码、收款码、小票机、厨房黑名单、成员寄存等。
2. **额度限制**：免费版菜品 50 道、分类 5 个，进度条可视化引导升级。
3. **虚拟币**：AI 生图消耗 2 币/次；积分（66.00）可支付菜价（"可用于开启积分支付"）、兑换会员。
4. **广告**：随机点菜页信息流广告（朴朴超市）、个人中心周边 Banner。
5. **等级**：厨房 Lv.0 等级体系；「成为大厨」纪念日。
