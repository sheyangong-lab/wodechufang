# 共享厨房 App · 复刻方案与需求设计 v1.0

> 配套文档：[页面功能分析.md](./页面功能分析.md)（原版 17 张截图的逐页拆解，UI 蓝本）
> 目标平台：**Android + 鸿蒙 HarmonyOS（含 NEXT）**
> 本文档在原版基础上落实 4 项新需求：
> 1. 商业化设计，含**后台管理系统**（管理 VIP 账号和厨房）
> 2. 主体色改为**浅黄色暖色调**
> 3. 新增**记账功能**（菜品可设价，订单自动入账）
> 4. 账本支持**软件内查看 + 导出 Excel**

## 一、信息架构调整

### 底部导航（5 Tab，方案定稿）

| Tab | 内容 | 变化 |
|-----|------|------|
| 厨房 | 菜单点单/修改、分类管理 | 不变 |
| 订单 | 厨房订单 / 我下过的单 | 不变 |
| **账本** 🆕 | 收支总览、记一笔、明细、统计、导出 Excel | **新增一级 Tab** |

- 备选方案（若追求与原版完全一致）：保留 管理 Tab，把「账本」做成订单页第三个子 Tab（厨房订单 / 我下过的单 / 账本）。

## 三、菜品价格与订单（记账的数据来源）

- 编辑菜谱页已有「请输入价格」字段 → 升级为**必填参与记账**：默认价必填；开启多规格时每个规格单独定价。
- 购物车/下单流程：菜品单价 × 数量 = 订单实付金额；支持整单备注。
- 订单状态流转：待完成 → 已完成 / 申请退单 → 已退单。
- **记账联动规则**：
  - 订单标记「已完成」→ 自动生成一条收入流水（来源=订单，关联订单号，可点击跳转订单详情）。
  - 订单「已退单」→ 自动生成冲销流水（负向收入），账本保留完整痕迹。
  - 「未完成」订单不进账本。
- 菜价也可设为 0（免费菜/自家菜），0 元订单不产生流水但仍计入订单统计。

## 四、记账模块详细设计

### 4.1 账本总览页（Tab 首页）
- **月份切换器**：◀ 2026年08月 ▶（默认当月）。
- **三卡摘要**：本月收入 / 本月支出 / 本月结余（收入-支出），点击卡片跳转对应明细（带筛选）。
- **图表区**：
  - 日收支柱状图（当月每日收/支双柱）；
  - 支出分类饼图（食材采购/设备/水电燃气/其他）。
- **菜品销售排行**（来自订单）：菜品名、本月销量、销售额、占比条。
- **操作**：「+ 记一笔」主按钮、「导出 Excel」、「统计」入口。
- **权限**：仅店长/管理员角色可见整个 Tab；普通成员显示引导页（"账本仅店长可见"）。

### 4.2 记一笔表单
| 字段 | 说明 |
|------|------|
| 类型 | 收入 / 支出（分段选择器） |
| 金额 | 必填，数字键盘，两位小数 |
| 分类 | 收入：菜品销售（默认，自动关联时不可选）/ 其他收入；支出：食材采购 / 厨房设备 / 水电燃气 / 其他 |
| 日期 | 默认今天，可选过去日期（补记） |
| 备注 | 选填，50 字 |
| 凭证图 | 选填，最多 3 张 |

### 4.3 收支明细列表
- 按日分组（日期头 + 当日小计），条目：分类图标 + 备注/关联订单摘要 + 金额（收入暖橙 +，支出暖绿 −）。
- 筛选：类型（全部/收入/支出）、分类、时间范围。
- 自动流水带「订单」角标，点击跳订单；手动流水可编辑/删除；自动流水不可删，只能通过订单退单冲销。

### 4.4 Excel 导出
- 入口：账本页「导出 Excel」→ 弹窗选范围（本月 / 上月 / 自定义起止）→ 服务端生成 → 客户端保存到「下载」并通过系统分享面板分享（Android SAF / 鸿蒙 Share Kit）。
- **文件名**：`{厨房名}-账本-{起}至{止}.xlsx`
- **Sheet 结构**：
  1. **汇总**：期间收入合计、支出合计、结余、完成订单数、客单价、退款金额；
  2. **收入明细**：日期、来源（订单/手动）、关联订单号、菜品摘要、金额、经手人、备注；
  3. **支出明细**：日期、分类、金额、备注、经手人；
  4. **菜品销售统计**：菜品名、销量、销售额、占比（降序）。
- 表头加厨房名 + 生成时间；金额列保留两位小数。
- 服务端实现推荐 EasyExcel（阿里，Java 系）；文件保留 7 天缓存，同参数二次导出直接下载。

## 五、商业化设计

### 5.1 会员体系
- **厨房会员**（店长购买，权益作用于整个厨房）：

| 权益 | 免费版 | 厨房会员 |
|------|--------|----------|
| 菜品额度 | 50 道 | 500 道 |
| 分类额度 | 5 个 | 50 个 |
| 批量添加菜谱 | ✕ | ✓ |
| 下单表单自定义 | ✕ | ✓ |
| 厨房桌码 / 收款码 / 小票机 | ✕ | ✓ |
| 厨房黑名单 | ✕ | ✓ |
| 经营分析 / 备份导出 | ✕ | ✓ |
| AI 生图 | 每月 2 次 | 每天 5 次 |

- **套餐**（示例价，后台可改）：月卡 ¥12 / 季卡 ¥30 / 年卡 ¥98。
- **激活方式**：
  - 兑换码（后台批量生成，线下/活动发放）——初期主推，无支付资质也能跑；
  - 在线支付（微信支付，Android 直接拉起；鸿蒙走华为 IAP/聚合支付）——二期接入。
- 个人积分体系保留（签到、下单得积分，积分可抵扣菜价）。

### 5.2 后台管理系统（Web，管理员专用）

| 模块 | 功能 |
|------|------|
| 管理员登录 | 账号密码 + 角色权限（超管/运营/客服） |
| **VIP 账号管理** | 按用户名/标识/手机号搜索；查看会员状态与到期时间；**开通 / 续期 / 更换套餐 / 手动关闭 VIP**；赠送积分；封禁账号 |
| **厨房管理** | 按厨房码/名称/店长搜索；查看额度使用情况；**手动调整菜品/分类额度**；开通/关闭厨房会员；封禁/解封厨房；转移创始人；删除厨房 |
| 兑换码管理 | 批量生成（指定套餐+有效期+数量）、导出码表、查看核销状态、作废 |
| 套餐管理 | 增删改套餐、定价、权益配置 |
| 交易/流水 | 会员购买记录、兑换记录、退款处理 |
| 数据看板 | 用户/厨房增长、活跃、付费转化、收入曲线 |
| 系统通知 | 全员/定向推送公告与消息 |

## 六、数据模型总览

```
User            用户：昵称、头像、标识、积分、vip_expire_at、状态
Kitchen         厨房：名称、厨房码、店长id、等级、菜品/分类额度、会员到期、公告
KitchenMember   成员：厨房id、用户id、角色(店长/成员/顾客)、备注、加入时间
Category        菜谱分类
Dish            菜谱：名称、描述、图、默认价、多规格(规格+价)、分类、推荐星级、
                用料、步骤、营养成分、库存、售罄、是否分享广场
Order           订单：厨房、买家、状态、总金额、日期时间
OrderItem       订单项：菜品快照、规格、单价、数量
LedgerEntry     账本流水：厨房、类型(收/支)、来源(订单/手动)、关联订单id、
                分类、金额、日期、备注、凭证图、经手人
VipPlan         会员套餐：名称、时长、价格、权益配置
VipOrder        会员交易：用户、套餐、金额、支付方式、状态
RedeemCode      兑换码：码、套餐、批次、状态(未用/已用/作废)、核销人/时间
AdminUser       后台管理员：账号、密码哈希、角色
```

关键约束：账本流水以厨房为单位隔离；订单流水与订单外键关联且不可物理删除；所有金额用「分」存储（整型）避免浮点误差。

## 七、技术架构建议

| 层 | 方案 | 说明 |
|----|------|------|
| 客户端 | **Flutter（鸿蒙社区版 flutter_flutter_ohos）** | 一套代码出 Android + 鸿蒙双端；备选 uni-app x（Vue 系，鸿蒙支持已落地，若更熟 Vue 可选） |
| Excel（客户端侧） | `excel` / `syncfusion_flutter_xlsio` 插件 | 离线兜底方案；主力走服务端生成 |
| 后端 | Spring Boot 3 + MySQL 8 + Redis + MinIO(图片) | 金额用分、JWT 登录、接口按角色鉴权 |
| Excel（服务端） | EasyExcel | 按第六节 Sheet 结构生成 |
| 后台 Web | Vue 3 + Element Plus + ECharts（可直接基于若伊/RuoYi 二开） | 覆盖第五节全部模块 |
| 通知 | 个推/UniPush + 鸿蒙 Push Kit | 订单提醒、系统通知 |

> 若团队更熟悉 Vue/小程序生态：客户端换 uni-app x 同样能出 Android + 鸿蒙双包，页面结构可直接对照原小程序写法迁移；Flutter 胜在性能与长期维护。两者后端与后台方案完全相同。
